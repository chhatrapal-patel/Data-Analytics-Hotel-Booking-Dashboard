# Data-Analytics-Sales-Dashboard
Data analytics project featuring exploratory data analysis, data visualization, and an interactive Power BI dashboard.
📊 Data Analytics & Power BI Dashboard

A data analytics project combining Python-based exploratory data analysis with an interactive Microsoft Power BI dashboard to transform raw data into meaningful insights and visualizations.

⸻

📌 Project Overview

This project demonstrates an end-to-end data analytics workflow, starting from data exploration and preprocessing in Python and progressing to interactive business intelligence and dashboard development using Power BI.

The project focuses on extracting meaningful patterns and insights from data through:

* Data exploration
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Data visualization
* Business intelligence
* Interactive dashboard development
* KPI analysis

🚀 How to Use

Python Analysis

Open:

Data_Analysis.ipynb

using Jupyter Notebook, JupyterLab, or Google Colab.

Install the required Python libraries if necessary:

pip install pandas numpy matplotlib seaborn

Then execute the notebook cells sequentially.

Power BI Dashboard

Download:

Sales_Analytics_Dashboard.pbix

and open it using Microsoft Power BI Desktop.
